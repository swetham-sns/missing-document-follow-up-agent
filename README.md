Missing Document Follow-up Agent

Project Overview

The Missing Document Follow-up Agent is an automated system designed to track insurance claim documents, identify missing documents, and send reminders to customers.

Problem Statement

Insurance companies and Third Party Administrators (TPAs) often face delays because customers submit incomplete claim documents. Manual follow-ups consume time and delay claim processing.

Objectives

- Identify missing claim documents.
- Track document submission status.
- Send automatic email reminders.
- Identify overdue claims.
- Maintain organized claim records.

Key Features

1. Automated Document Checking
2. Email Reminder System
3. Overdue Claim Detection
4. CSV-Based Claim Data Management
5. Document Status Tracking

Technologies Used

- Python
- Google Sheets
- CSV
- Pandas
- Google Authentication
- GitHub

Workflow Process

1. Read claim details.
2. Check required documents.
3. Identify missing documents.
4. Send reminder emails.
5. Check overdue submissions.
6. Update claim status.

Sample Database

A sample CSV database is included for testing the document tracking process.

Expected Outcome

To reduce manual work, improve document collection, and make insurance claim processing faster and more organized.
